# curs_project — АИС «Ресторан»

Курсовой проект по МДК 11.01 «Технология разработки и защиты баз данных».

**Тема:** «Разработка веб-сайта для организации деятельности ресторана».

## Назначение

Информационная система автоматизирует деятельность ресторана: ведение меню,
приём заказов, бронирование столиков, оплату, работу сотрудников, аудит действий
и формирование статистической отчётности.

## Стек

- **СУБД:** Microsoft SQL Server 2019+ (T-SQL, хранимые процедуры, функции, триггеры)
- **Серверная часть:** ASP.NET Core 10 (REST API), ADO.NET / Microsoft.Data.SqlClient
- **Микросервис отчётности:** отдельный ASP.NET Core-сервис (ядро + сервис отчётности)
- **Клиент:** HTML5, CSS3, JavaScript, Chart.js
- **Тестирование:** xUnit, SQL unit-тесты, k6 (нагрузочное), Postman/Newman
- **DevOps:** Git, GitHub Actions, Docker, Docker Compose

## Структура репозитория

```
01_Документация/            — пояснительная записка и руководства
02_Проектирование_БД/       — ERD, IDEF0, DFD, Use Case, схемы
03_SQL_скрипты/             — создание БД, ограничения, данные, CRUD, процедуры,
                              триггеры, RBAC, транзакции, backup, статистика, тесты
04_Клиент-сервер_и_API/     — REST API, микросервис отчётности, веб-интерфейс
05_Тестирование/            — тест-планы, кейсы, результаты, нагрузочные тесты
07_DevOps/                  — CI/CD, Docker, вспомогательные скрипты
```

## Быстрый старт

1. Развернуть базу данных скриптами из `03_SQL_скрипты` в указанном порядке
   (01 → 02 → 03 → 04 → 05 → 09 → 06 → 07 → 08).
2. Настроить строку подключения в `04_Клиент-сервер_и_API/src/RestaurantApi/appsettings.json`.
3. Запустить ядро API и микросервис отчётности:

```powershell
dotnet run --project 04_Клиент-сервер_и_API/src/RestaurantApi
dotnet run --project 04_Клиент-сервер_и_API/src/RestaurantReports
```

4. Открыть веб-интерфейс: `http://localhost:5000`.
